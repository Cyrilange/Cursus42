# 42 Cursus — Cyril Salamit

My journey through the 42 school curriculum. All projects written in C or C++ unless ft_transcandence and Inception(docker).

---

## Projects

### 🔧 libft
My own C library reimplementing standard functions like `ft_strlen`, `ft_memcpy`, `ft_split` and more. The foundation used in almost every project after.

---

### 📄 get_next_line
A function that reads a file line by line using a static variable and a buffer. Handles multiple file descriptors simultaneously.

---

### 🖨️ printf
A custom implementation of `printf` supporting formats: `%c`, `%s`, `%d`, `%i`, `%u`, `%x`, `%X`, `%p`, `%%`.

---

### 🔄 push_swap
A sorting algorithm project. Given a stack of integers, sort them using two stacks (a and b) with a limited set of operations in the minimum number of moves.

---

### 🍽️ phylo (Philosophers)
The classic dining philosophers problem solved with threads and mutexes (or processes and semaphores). Focuses on concurrency, race conditions, and deadlock prevention.

---

### 💬 Minitalk
A communication program between a client and server using only UNIX signals (`SIGUSR1` and `SIGUSR2`). The client sends a string bit by bit to the server.

---

### 🐍 so_long
A small 2D game using the MiniLibX graphical library. The player moves a character through a map, collects items, and reaches the exit. Taught window management, events, and basic game loops.

---

### 🧱 Cub3D
A raycasting engine inspired by Wolfenstein 3D, built with MiniLibX. Renders a 3D perspective from a 2D map using the DDA algorithm. Implements textures, floor/ceiling colors, and player movement.

---

### 🐚 minishell
A fully functional shell written in C. Supports pipes, redirections (`<`, `>`, `<<`, `>>`), environment variables, built-ins (`cd`, `echo`, `export`, `unset`, `env`, `exit`), and signal handling.

---

### 🐳 Inception
A Docker infrastructure project. Sets up a multi-service environment with Docker Compose including NGINX, WordPress, and MariaDB, each in its own container with persistent volumes and TLS.

---

### 🖥️ C++
A series of C++ modules (00–09) covering Object-Oriented Programming: classes, inheritance, polymorphism, templates, STL containers, and exceptions.

---

### 🏓 ft_transcendence
The final 42 project. A full-stack web application featuring a real-time multiplayer Pong game, OAuth2 login with the 42 API, user profiles, chat, and a tournament system. Built with Node.js/Express backend, SQLite database, and a JavaScript frontend, served over HTTPS via NGINX.
